INVESTMENT PHILOSOPHY

"첫째, 돈을 잃지 마라. 둘째, 첫 번째 원칙을 절대 잊지 마라."

US Capital Preservation은 단순한 고수익 추구가 아닌 철저한 자본 보존(Capital Preservation)과 MDD(최대 낙폭) 극소화를 목표로 설계된 미국 주식 멀티에셋 퀀트 트레이딩 시스템입니다. 투자에서 50%의 원금 손실이 발생하면 원금 회복에만 100%의 수익률이 필요합니다. 대형 하락장(Drawdown)을 선제적으로 차단하고 변동성을 통제하는 것이 장기 복리 승률을 결정짓는 핵심입니다.

목표 최대 낙폭 (Target MDD)
< 5.0%
S&P 500(-24%)의 1/5 수준
목표 연복리 수익률 (CAGR)
15.0% ~ 20.0%
손실 최소화를 통한 안정적 복리
연간 목표 변동성 (Vol Target)
10.0%
시장 위험도에 따른 동적 현금 비중

🏗️ 4계층 파이프라인 아키텍처 (Layered Architecture)

데이터 수집부터 시장 국면 감지, 최적화 배분, 증권사 API 실행까지 4단계로 유기적 구동

머신러닝 계층적 군집화(HRP)로 역행렬 오류 없이 안정적인 리스크 균등 가중치 계산

Execution Broker

execution/nh_trader.py

🚦 1. 거시 시장 국면 전환 (Regime Switching Matrix)

추세(200일 이동평균선)와 변동성(VIX 지수)의 2×2 매트릭스로 시장 위험도를 실시간 통제

시장 국면 (Regime) 조건식 (Trigger) 포트폴리오 자산 전략 위험도 수준
BULL CALM (상승 안정) SPY > 200 DMA && VIX < 20.0 주식(SPY, QQQ) 및 위험자산 적극 배분, HRP 최적 가중치 100% 부여 LOW
BULL VOLATILE (상승 불안) SPY > 200 DMA && VIX ≥ 20.0 주식 비중 감축, 금(GLD) 및 중기채(IEF) 비중 확대, 헤지 강화 MEDIUM
BEAR CALM (하락 안정) SPY ≤ 200 DMA && VIX < 20.0 주식 비중 최소화, 장기채(TLT) 및 현금성 자산(SGOV) 위주 방어 ELEVATED
BEAR VOLATILE (위기/공황) SPY ≤ 200 DMA && VIX ≥ 20.0 🚨 위기 대응 프로토콜 발동: 위험자산 전량 청산, 100% SGOV / 현금 파킹 CRITICAL
핵심 포인트: 2008년 금융위기나 2022년 금리인상기와 같은 역사적 약세장은 모두 BEAR_VOLATILE 조건을 충족합니다. 이 국면에서는 자산 배분의 기교를 부리지 않고 100% 현금/단기국채로 대피하여 자본을 완전히 보존합니다.

🧠 2. 계층적 리스크 패리티 (HRP, Hierarchical Risk Parity)

Marcos López de Prado (2016)가 제안한 머신러닝 기반 차세대 포트폴리오 최적화 알고리즘

기존 MPT(마코위츠 평균-분산 최적화)의 한계

마코위츠 MPT는 공분산 행렬의 역행렬(Σ-1)을 계산해야 합니다.

  • 두 자산의 상관계수가 높으면 행렬식(Determinant)이 0에 가까워져 역행렬이 극도로 불안정해집니다.
  • 과거 데이터의 사소한 오차나 노이즈가 역행렬을 통과하면서 기하급수적으로 증폭됩니다.
  • 결과적으로 특정 자산에 몰빵(Concentration)되거나 극단적인 가중치가 산출되어 실전에서 실패합니다.

HRP(계층적 리스크 패리티)의 혁신적 해결책

HRP는 역행렬을 전혀 계산하지 않고 그래프 이론과 머신러닝 군집화(Clustering)를 사용합니다.

  • 거리 메트릭: 상관계수 ρ로부터 정보 거리 di,j = √((1 - ρi,j) / 2)를 정의합니다.
  • 트리 군집화: 유사한 움직임을 보이는 자산들을 덴드로그램(Dendrogram) 트리로 묶습니다.
  • 재귀적 이분법: 상위 클러스터에서 하위 자산으로 리스크 역수 비율에 따라 가중치를 하향 배분합니다.
// HRP 재귀적 이분법(Recursive Bisection) 가중치 분할 수식
V_left = cluster_left.T @ Cov @ cluster_left
V_right = cluster_right.T @ Cov @ cluster_right
alpha = 1.0 - (V_left / (V_left + V_right)) # 변동성이 작은 쪽에 더 높은 가중치 부여
weights[left] *= alpha; weights[right] *= (1.0 - alpha)

⚡ 4. 증권사 오픈API 실전 주문 집행 (NH Broker Pipeline)

NH투자증권(나무증권 / NHPLUG) OpenAPI 연동을 통한 주문 최적화

🔑 24시간 토큰 로컬 캐싱

운영 도메인(api.nhplug.com:8443)에서 발급받은 OAuth 2.0 접근 토큰(24시간 유효)을 로컬 파일(.nh_token_cache.json)에 캐싱하여 만료 5분 전까지 재사용합니다. 불필요한 토큰 재발급 호출을 원천 차단합니다.

🔄 매도 선행 후 매수 (Sell First, Buy After)

리밸런싱 시 목표 가중치보다 높은 자산의 매도 주문을 먼저 전송하여 예수금과 구매력을 확보한 뒤 매수 주문을 순차 실행합니다. 미수금 발생이나 잔고 부족 오류를 방지합니다.

🛡️ 모의투자 및 드라이런 안전 장치

기본 설정 dry_run: true 모드에서는 실제 주문 API를 호출하지 않고 가상 주문 체결 및 수수료(9bp) 반영을 시뮬레이션합니다. 검증 완료 후 dry_run: false로 실전 전환됩니다.
