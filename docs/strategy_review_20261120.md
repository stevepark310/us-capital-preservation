## 공통 약점 세 가지와 대응

1. **국면을 보지 않는다.** 모든 전략이 신호 강도만 본다. → 신규 모델의 다중 확인(추세·패닉·추세 없는
   RISK_OFF 배제) + 라이브 VIX 28 하드 차단.
2. **손실 폭이 전략마다 제각각이다.** 사다리 2.5%, v2 0.75×ATR, DIP 1.5×ATR(최대 15%), NVDA -13.4%.
   → 포지션 손실 하드캡 **-8% / -$25**로 상한을 하나로 묶고, 신규 모델의 손절도 8%에서 클램프.
3. **청산이 한 곳에서 결정되지 않는다.** 브래킷·평단 사다리·감시 스크립트가 각자 규칙을 들고 있었다.
   → `core/exit_authority.py`로 소유자를 하나로 정하고, `avg_anchor_plan.json`은 참고값으로만 남긴다.
