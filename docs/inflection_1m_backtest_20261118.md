## 1. 방법

### 1.1 1분봉 가용 데이터 — 실측으로 확정한 범위

yfinance 1분봉은 **최근 30일 이내**만 조회된다. 7일 단위 청크로 요청하고, 범위를 넘기면 다음 메시지로 거부된다.

```
$SOXL: 1m data not available for startTime=... and endTime=...
The requested range must be within the last 30 days.
```

실측 결과(원본 응답은 JSON `data_availability.fetch_chunks`에 청크별로 기록):

| 항목 | 실측값 |
|---|---|
| **가용 기간** | **2026-10-19 ~ 2026-11-17** |
| **가용 세션** | **22개** (10-19,20,21,22,23 / 10-26~30 / 11-02~06 / 11-09~13 / 11-16,17) |
| 봉 수 | 종목당 **8,580봉** (390봉 × 22세션), 4종목 합 **34,320봉** |
| 세션당 봉 수 | **전 세션 390봉** (min=max=390, 조기폐장 없음) |
| 결측 분 | **0** (기대 390분 전부 존재) |
| `Close` NaN / 거래량 0 | **0 / 0** |
| **지난 5거래일(11-11~11-17) 포함** | **포함** (`five_day_window_covered: true`) |
| **60일(2026-08-25~) 1분봉** | **조회 불가** — 30일 제한. **미확보 기간은 추정하지 않았다.** |

1분봉 확보를 위해 사용한 7일 청크(SOXL 기준, 4종목 동일):

| 청크 | 행 | 실제 반환 |
|---|---|---|
| 2026-10-19~10-26 | 1,950 | 10-19 ~ 10-23 |
| 2026-10-26~11-02 | 1,950 | 10-26 ~ 10-30 |
| 2026-11-02~11-09 | 1,950 | 11-02 ~ 11-06 |
| 2026-11-09~11-16 | 1,950 | 11-09 ~ 11-13 |
| 2026-11-16~11-18 | 780 | 11-16 ~ 11-17 |

→ **비교 창은 1분봉이 존재하는 22세션(10-19~11-17)으로 통일**했다. 10분봉·5분봉도 같은 22일에 맞춰 잘랐으므로 세 주기의 비교는 **동일 이벤트·동일 기간**에서 성립한다. 60일 창의 10분봉 수치는 직전 연구 값을 참조로만 병기한다.

### 1.2 1분봉 → 10분봉 집계 정합성 (기존 5분봉 데이터와 대조)

| 종목 | 비교 봉 | `Close` 최대 괴리 | 0.01% 초과로 다른 봉 | `Volume` 동일 비율 |
|---|---|---|---|---|
| SOXL | 858 | **0.0000** | **0** | 30.2% |
| TQQQ | 858 | **0.0000** | **0** | 66.9% |
| SOXS | 858 | **0.0000** | **0** | 66.2% |
| SQQQ | 858 | **0.0000** | **0** | 89.9% |

**OHLC는 1분봉 집계와 기존 5분봉 집계가 858봉 전부 소수점까지 일치**한다(판정·체결 가격의 동일성 확보). `Volume`은 일부 봉에서 다르다(Yahoo 5분봉 거래량 집계 이슈, 예: 09:50봉 1m 합 68.7M vs 5m 합 5.39M). 따라서 `+거래량` 필터는 **10분봉은 10분 거래량 20봉 평균, 1분봉은 1분 거래량 20봉 평균**이라는 서로 다른 의미를 가지며, 이 차이는 §4.2에서 `+거래량`이 1분봉에서 손익 개선(c=1.5: −$133→−$57)과 악화(c=2.5: −$4→−$32)로 갈리는 원인이 된다(해석에 주의).

### 1.4 체결·비용·포지션 규약 (세 주기 모두 동일)

| 항목 | 값 |
|---|---|
| 판정·체결 | 해당 봉 종가에서 계산 → **그 봉 종가 체결**(룩어헤드 없음) |
| 비용 | 왕복 **0.24%**(편도 12bp), 슬리피지 민감도는 편도 +12bp(왕복 0.48%) |
| 예산·수량 | 건당 **$150**, 정수주(NH Open API) |
| 손절 | `clamp(0.75×ATR%, 1.5%, 15%)` — 1분·5분·10분 모두 ATR 하한 1.5%에 걸려 **사실상 1.5% 고정** |
| 청산 A안 `trail` | 샹들리에 `peak − 1.5×ATR` — **ATR을 해당 봉 주기로 계산**(22일 평균 ATR%: 10분봉 1.43% / 1분봉 0.41% → 추적 폭 2.14% / 0.61%) |
| 청산 B안 `flip` | 진행 극단 대비 c% 반전에서 청산 |
| 동시 보유 | 페어당 1포지션(최대 2) |
| 게이트 | 개장 유예 09:30~10:00(DIP 설정만), 신규 마감 14:30, 15:50 강제청산 |
| 이벤트 포착 정의 | 이벤트 `[t0,t1]` 안에서 같은 종목·같은 방향으로 진입한 거래 1건 이상(직전 연구와 동일) |

> 청산 A의 ATR 주기 의존성은 이 연구의 **핵심 발견 중 하나**다(§4.5). 1분봉으로 판정을 옮기면 진입만 1분이 되는 것이 아니라 **추적청산 폭도 1분 스케일로 줄어들어** 회전이 폭증한다.

## 2. 오라클 지연 — 1분 vs 5분 vs 10분 (22일 77개 레그)

피벗 봉 종가(`t0`)에 진입해 레그 끝(`t1`)에 청산하는 **오라클**에서, `k`분 늦게 진입하면 오라클 수익이 얼마나 남는가. 1분봉 종가로 체결했다.

| 지연 | 진입 이탈(평균) | **오라클 보존율** | 77레그 합계 | 음수 레그 비율 | 남은 시간 |
|---|---|---|---|---|---|
| 0분(오라클) | 0.00% | **100.0%** | **+$578.73** | 0.0% | 67.3분 |
| **1분** | 0.51% | **95.5%** | +$552.57 | 0.0% | 66.3분 |
| 2분 | 0.66% | 92.3% | +$534.45 | 0.0% | 65.3분 |
| 3분 | 0.77% | 88.6% | +$512.65 | 0.0% | 64.3분 |
| **5분** | 1.06% | **81.9%** | +$474.24 | 0.0% | 62.3분 |
| **10분**(10분봉 1봉) | 1.71% | **64.8%** | +$374.85 | 14.3% | 57.3분 |
| 15분 | 2.11% | 57.0% | +$329.89 | 5.2% | 52.3분 |
| 20분 | 2.34% | 51.9% | +$300.49 | 11.7% | 47.3분 |
| 30분 | 2.66% | 46.0% | +$266.19 | 16.9% | 37.3분 |
| 60분 | 3.53% | 38.3% | +$221.49 | 9.3% | 8.5분 |

5거래일(24개) 창: 0분 $188.28 → **1분 $175.99(95.5%)** → 5분 $158.18(81.9%) → **10분 $117.76(64.8%)** → 20분 $98.36(51.9%) → 30분 $82.11(43.6%) → 60분 $65.56(34.8%)

**읽는 법**
1. **지연 비용은 앞 10분에 몰려 있다.** 1분 늦으면 −4.5%, 5분 −18%, **10분 −35%**. 10분 이후는 분당 −1% 안팎으로 완만해진다(20→30분 −5.9%p).
2. **10분봉 1봉 지연 = 1분봉 10분 지연**이 정확히 같은 금액($117.76 vs $117.77)이다. 즉 "봉 주기를 줄인다"는 것은 **①지연을 줄일 수 있는 상한을 10분에서 1분으로 넓히는 일**이고, ②그 상한을 실제로 쓰려면 확인 임계 `c`도 같이 낮춰야 한다.
3. 이론상 1분봉이 10분봉보다 9분 빨리 잡으면(c=2.5%: 20분→11분) 오라클 기준 **77레그 합계 약 $65(오라클의 11%)** 를 더 가져온다. **문제는 이 $65를 실제로 가져올 수 있느냐다 — §4가 그 답이다.**

### 4.5 왜 빨리 잡았는데 같은 돈만 버는가 — 공유 레그의 실제 거래

두 주기가 **함께 포착한 같은 이벤트**에서, 그 이벤트에 걸린 첫 거래의 평균을 비교했다.

|---|---|---|---|---|
| 2.5 | 추적 | 36 | 0.825% / 105.3분 / 34.7분 | **0.782% / 9.9분 / 25.5분** |
| 2.5 | 반전 | 64 | 0.003% / 45.3분 / 30.5분 | 0.330% / 27.4분 / 17.3분 |
| 1.5 | 추적 | 34 | 0.872% / 89.7분 / 36.5분 | **0.859% / 9.7분 / 11.7분** |
| 1.5 | 반전 | 70 | 0.327% / 38.3분 / 18.4분 | 0.294% / 16.6분 / 8.0분 |

**1분봉은 9~25분 먼저 진입하고, 같은 gross(0.86%)를 1/10의 시간(9.7분)에 번다.** 즉 1분봉의 이득은 "더 많이 번다"가 아니라 **"같은 것을 더 빨리 번다"** 이다. 그런데 그 다음 거래(재진입)의 gross 기대값이 0.18%로 수수료 0.24%보다 작아서, **빨리 번 만큼 빨리 잃는다.** 회전이 이익이 되려면 재진입 신호에 엣지가 있어야 하는데, 1분봉 재진입 신호에는 엣지가 없다(§7 트리거 품질).

원인은 청산 규격에도 있다. 1분봉 ATR%는 평균 **0.41%**로 10분봉 **1.43%**의 약 1/3.5이고, `trail 1.5×ATR` 폭이 **2.14% → 0.61%**로 좁아진다. 1분 노이즈의 진폭이 이 폭을 넘나들어 **9.9분** 만에 청산된다(10분봉은 105분). 진입만 1분으로 줄이고 청산은 10분 스케일로 두는 절제가 §4.6이다.

### 4.6 절제 — 1분봉 판정 + **10분봉 스케일 청산**

1분봉 판정 배열에 **직전에 완료된 10분봉의 ATR%**를 주입했다(룩어헤드 없음: 09:31 봉은 전일 16:00 봉의 ATR%를 갖는다). 손절은 1.5% 하한으로 같으므로, 실제로 달라지는 것은 추적 폭 하나다. `flip` 행이 원래 1m 값과 완전히 동일한 것으로 주입이 ATR 경로에만 작용했음이 검증된다.

| c (%) | 1분봉 · 1분 청산 | 1분봉 · **10분 청산** | 차이 | 보유(1m→10m 청산) |
|---|---|---|---|---|

- 동일 빈도에서 순손익은 1분봉 −$41.99 / −$9.29 / +$0.86, 10분봉 **+$43.10**이다. 빈도를 맞춰도 시간 이득(2.5분)이 거래 구성 차이를 뒤집지 못한다.

## 8. 결론과 권고

### 8.1 동훈님 질문에 대한 최종 답

1. **1분봉으로 바꾸면 진입은 실제로 빨라진다** — 지연 20분→11분(c=2.5%), 10분→6분(c=1.5%), 진입 이탈 3.10%→2.18%. 오라클 보존율도 10분 지연 64.8% → 1분 지연 95.5%로 오른다(1분 = 오라클의 95.5%).

## 9. 이 연구가 말하지 않는 것

- 1분봉은 **최근 30일(22세션)만** 존재한다. 60일 비교(직전 연구)와 같은 절대 손익 비교는 불가능하며, 이 문서의 22일 수치는 **레짐 편향**(이벤트 3.5건/일 vs 60일 평균 1.8건)을 포함한다.
- 1분봉 판정은 **1분 ATR·1분 거래량**이라는 다른 스케일의 지표를 쓴다. `+거래량` 필터 결과는 그 규격 차이의 영향이며, 10분봉 필터와 같은 의미로 읽으면 안 된다(§4.2).
- 15:50 강제청산은 봉 주기가 짧을수록 최대 9분 먼저 체결된다(1m은 15:49봉 종료, 10m은 15:50). 세 주기 모두 같은 규칙을 적용했으나 이 미세한 비대칭은 남아 있다.
- 인버스 ETF 배율(데이터 −0.96x vs 실제 −3x) 때문에 숏 측 USD 손익은 보수적으로 계산됐다. 숏을 3배로 반영해도 손실 주원인이 건수×수수료이므로 **부호는 바뀌지 않는다**.
- 22세션·77이벤트·최대 2,104건, 최고 설정 t=1.62 — **통계적으로 유의하지 않다.** 방향성(1m < 5m < 10m)은 일관되나 크기는 신뢰구간이 넓다.
- 이벤트 정의는 10분봉 지그재그에 고정했다. 1분봉 지그재그로 이벤트를 다시 정의하면 "정답"이 달라져 비교가 성립하지 않는다(1분 지그재그는 노이즈로 수백 개 레그를 만든다).
