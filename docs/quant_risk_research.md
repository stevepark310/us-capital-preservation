# CUBE Quant Risk V1 — 자본보존 우선, 레버리지 기회 선택

2026-11-20 연구·실행 설계. 수익·무손실·손절가 체결 보장 없음.

## 실측과 문제

- `data/1y_backtest_report.json` 구버전 1년 시뮬레이션: -41.57%, MDD -43.19%, 267건. **실제 손익 아님.**
- `data/regime_ab_20261120.json`의 별도 5년 데이터 레짐 실험: V2 OOS 38건, EV 4.484%, PF 2.86, 전체 MDD -12.84%. 실제 체결·평가용 전진검증이 아니며 과최적화/생존편향 위험이 있다.
- 동일 실험의 무조건 SQQQ 헤지 추가 V3은 V2 대비 수익·MDD가 모두 열화(전체 수익 43.24% → 39.23%, MDD -12.84% → -13.26%). 따라서 **인버스 매수 = 무위험 헷지**라는 가정은 폐기.
- SQQQ 실제 1주 포지션의 장 마감 강제청산이 `05:40 KST`에 누락됨. `FAILSAFE_OVERDUE` 플래그와 다음 세션의 신규매수 동결을 연계하되, 청산을 보장하는 것은 아님.

## 운영 규칙

1. **브로커 계좌 조회 → 체결 확인 → 위험 확인 → 매도 우선 → 신규매수 후보 심사** 순서. 손절/기존 청산을 신규매수 위험 제한 때문에 막지 않는다.
2. 후보는 기존 허용 종목(SOXL, TQQQ, SOXS, SQQQ 등)만. 새로운 3배 상품/미검증 테마주는 자동 추가하지 않는다.
3. **동시 총위험**: 3배 ETF 명목금액 ≤ 계좌의 15%, 기초자산 배수로 환산한 gross 노출 ≤ 75%, 단순 합산 급락 스트레스 ≤ 계좌 5%. 반대 방향 레버리지도 상쇄하여 위험이 0이라고 계산하지 않는다.
4. **거래당 손절 위험**: 진입가 × 수량 × 계획 손절폭 ≤ 총자산 1%. 가격 갭·슬리피지는 별도의 추가 손실 위험이며 이 상한이 실제 손실 보장은 아님.
5. **변동성 타기팅**: 완료된 20일/60일 일봉 로그수익률 중 더 큰 연율화 변동성으로 3배 ETF 신규 수량을 줄인다. 표본 부족 시 확인 불가로 기록하고 gross/shock 상한 적용.
6. **지나간 청산**: 손절 시각 `force_exit_kst`가 지나도록 미청산인 종목이 있으면 신규매수 중단. 해당 포지션은 기존 청산 규칙과 승인·시장시간 조건을 유지하며 관리한다.
7. 최소 1주 예외가 주문 예산보다 큰 진입을 강요하지 않게 수정한다. 작은 계좌에서는 **0주/현금 유지**가 정상 판단이다.
8. 기존 NH 실계좌 주문가능액·매도가능량 직전 조회, 실거래 당일 한정 승인 게이트는 유지한다.
9. 모든 직원에게 `data/quant_risk_status.json`로 gross factor, stress, 청산연체 플래그를 공유한다. 분석 보고서는 주문을 내지 않는다.

## 추가 알고리즘 후보 — 아직 미승인, 그림자 모드에서 먼저 검증

- **멀티타임프레임 진입**: 전일 완료봉 추세 + 5분봉 VWAP 회복/하향 이탈 + RVOL + 매수·매도 호가 스프레드; 순간적 VIX 피크만으로 인버스 추격 금지.
- **변동성 모델**: EWMA(λ=0.94), ATR, 20d/60d realized volatility와 VIX 이견 감지. 지표 불일치면 신규 노출 줄이기.
- **단기 이익 실현**: ATR 기준 initial stop → 위험 1R 상승 후 break-even 이동 → 0.9–1.5 ATR 샹들리에 트레일. 단, 빈번한 작은 익절과 거래비용으로 순 EV가 음수라면 즉시 폐기.
- **시장상태 모델**: RISK_ON/NEUTRAL/RISK_OFF/CRISIS. CRISIS에는 롱 금지, 무조건 인버스는 금지(리스크 오프가 반전할 때도 3배 손실). 무포지션·SGOV도 유효한 선택.
- **유동성 리스크**: NH 실시간 bid/ask와 스프레드, 유효기간, 호가단위, 미체결을 확인한 뒤 주문. 시장가와 스톱리밋은 서로 다른 미체결·슬리피지 위험이 있다.
- **학습 및 배포 게이트**: RL/밴딧은 실현손익 기반 *오프라인 후보*만 만들고, 레짐별 OOS 30건 이상·워크포워드·거래비용 0.12/0.24/0.36%·부트스트랩 신뢰구간·MDD·연속 손실·시뮬레이터 체결 지연·종목 상관 스트레스 통과 후 수동 승인. 학습이 손절 상한이나 계좌 게이트를 완화하지 못한다.

## 검증 우선순위

1. 실제 **NH 브로커 측** 보호주문/OCO/서버 보관 가능 여부 검증. Github Actions 스케줄은 시간 보장 불가이므로 10분 배치만 손절 방어선으로 사용하지 않는다.
2. 주문/체결/미체결/수정·취소의 멱등성, 자동 매매 계좌 원장 대조, GitHub CI·스케줄 지연 보완을 별도로 검증한다.
3. 최근 백테스트 V2의 데이터/미래정보 누수/거래비용/2025 부진 기간 검증 후 후보 전략 적용 여부를 판단한다.
